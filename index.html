KeySocial社媒助手（Chrome 扩展）隐私政策

生效日期：2026-10-01（适用于 1.2.0 及以后版本）

「KeySocial社媒助手」是 KeySocial 内容工作台的配套 Chrome 扩展，在你自己的浏览器里、只在你于工作台里主动发起操作时运行，做两件事：

  1. 填写小红书笔记：把你在工作台里准备好的小红书笔记（标题、正文、话题标签、配图）填进小红书创作者中心的发布页，并停在发布按钮前。最终是否发布，由你本人点击。
  2. 导入公众号文章、小红书笔记或抖音视频为私有模板：你在工作台「我的模板 → 上传个人模板 → 粘贴链接」里粘贴指定内容的链接并点「导入」后，扩展在你的浏览器里打开对应页面，读取内容交还给工作台，保存为只有你自己可见、仅供仿写参考的模板。

一、扩展会处理哪些数据、交给谁

  • 笔记内容（标题、正文、话题标签、配图链接）：来自你在工作台页面点击「发布到小红书」时，页面经 Chrome 的扩展消息通道一次性传给扩展；扩展只把它们填进创作页。
  • 配图文件：扩展按页面传来的图片链接（KeySocial 的对象存储 keyfocushub-user-media.oss-cn-hangzhou.aliyuncs.com，带时效签名）下载图片，再交给创作页的上传控件，不发送到其它任何地方。
  • 小红书账号昵称与 ID：只用于填写前核对当前登录的创作者账号是不是你选定的那个，避免发错号；核对结果只回传给发起操作的工作台页面。
  • 公众号文章内容（网站内容）：只在你点「导入」之后、只从扩展自己为这次导入打开的那个 mp.weixin.qq.com 文章标签页读取，字段仅限：规范化后的文章链接、文章编号、文章类型、标题、公众号名称、正文 HTML、封面与正文图片的地址。扩展把它们交还给发起导入的工作台页面，由该页面提交到 KeySocial 服务器，保存为你的私有模板；图片由 KeySocial 服务器按这些地址从微信图片服务器下载保存。
  • 小红书笔记内容（网站内容）：只在你点「导入」之后、只从扩展自己为这次导入打开的那个 www.xiaohongshu.com 笔记标签页读取，字段仅限：精简后的笔记链接（只保留笔记编号，以及小红书用来打开这篇笔记的访问参数 xsec_token、xsec_source）、笔记编号、笔记类型、标题、正文、作者昵称、图片地址与尺寸、是否实况图；视频笔记还会读取视频与封面地址。扩展把它们交还给发起导入的工作台页面，由该页面提交到 KeySocial 服务器，保存为你的私有模板；图片和视频由 KeySocial 服务器下载保存。小红书分享链接里的追踪参数（例如分享人的账号 id appuid、share_id 等）在导入前就被丢弃，不交给工作台、不保存。
  • 抖音视频内容（网站内容）：只在你点「导入」之后、只从扩展为这次导入打开的 www.douyin.com 视频页读取视频编号、标题、作者昵称、封面地址、视频地址与时长。扩展将这些字段交还给工作台，由 KeySocial 服务器下载并保存视频及封面。分享链接里的追踪参数会被丢弃。

扩展本身没有自己的服务器，也不会主动向 KeySocial 或任何第三方服务器发送数据——以上数据都只经由发起操作的工作台页面流转。

二、扩展明确不读取、不保存的数据

  • 小红书、抖音与微信的账号密码、Cookie、登录状态，以及网页里的各类会话凭据（例如公众号链接里的 key、uin、pass_ticket 等参数——导入前会从链接里去掉）。
  • 小红书笔记页里的作者账号 id、头像、点赞收藏评论数、IP 属地、发布时间、评论，以及页面数据里的其它访问凭证字段。
  • 浏览器本地存储里的任何内容；文章的阅读数、评论；整页网页源码。
  • 你打开的其它标签页、其它网站上的任何内容。扩展不在你自己打开的微信、小红书或抖音页面上运行。
  • 扩展不在本地保存笔记或文章：内容只在这一次操作过程中存在于内存里，操作结束即消失。
  • 扩展不使用任何统计、埋点或崩溃上报服务。

三、扩展申请的权限及用途

  • scripting：在扩展自己打开的小红书创作页标签里注入填写逻辑；在扩展自己为导入打开的公众号文章、小红书笔记或抖音视频标签页里读取指定内容。这是扩展唯一申请的 API 权限。
  • 访问 creator.xiaohongshu.com：填写笔记内容的唯一目标站点。
  • 访问 keyfocushub-user-media.oss-cn-hangzhou.aliyuncs.com：下载你自己上传到 KeySocial 的配图。
  • 访问 mp.weixin.qq.com：只在你点「导入」后，读取扩展自己打开的那篇公众号文章。
  • 访问 www.xiaohongshu.com：只在你点「导入」后，读取扩展自己打开的那篇小红书笔记，并据标签页地址判断笔记是否打不开、是否停在登录或验证页。手机分享的短链（xhslink.com / xhslink.cn）由浏览器自己跳转，扩展不申请访问它们的权限。
  • 访问 www.douyin.com：只在你点「导入」后读取扩展自己打开的那条抖音视频。短链由浏览器自行跳转，扩展不申请短链域名权限。
  • 只接受来自以下 KeySocial 工作台域名的消息：test.keysocial.cn、keysocial.cn、test.keyfocus.cn、app.keyfocus.cn。其它任何网页都无法驱动本扩展。

四、你的控制权

  • 导入得到的模板只有你自己可见，你可以随时在「我的模板」里删除，模板与其图片、视频会一并删除。
  • 遇到微信的人机验证，或小红书要求登录、验证时，扩展不会替你操作、不会自动点击、也不会换网络重试，只把页面留给你本人完成。
  • 你可以随时在 Chrome 的扩展管理页里收回扩展对任一网站的访问权限，或直接卸载扩展。

五、不做的事

  • 不会替你点击「发布」，不会定时或自动发布。
  • 不会在小红书创作页，以及扩展自己为导入打开的公众号文章页、小红书笔记页、抖音视频页之外的网站注入代码。
  • 不会修改你的浏览器设置、搜索引擎或新标签页。

六、政策变更与联系方式

本政策如有变更，会在本页面更新并同步更新扩展版本说明。如有疑问，请通过 KeySocial 工作台内的支持渠道联系我们。
